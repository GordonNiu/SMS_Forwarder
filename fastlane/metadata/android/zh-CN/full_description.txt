短信转发器（SMS Forwarder）是一款专为家里留守备用机打造的极简开源工具。无任何第三方 SDK、无广告无统计、无第三方中转服务器，将收到的新短信直接通过 HTTPS 发送到你自己的 Telegram 机器人。

主要功能：
- 短信即时转发：将发件人、接收时间与短信正文直连发送至 Telegram 官方 API。
- 额外时区时间：支持在转发短信中同时附带另一个时区的时间，内置常用城市快捷选择与偏移搜索。
- 低功耗电量提醒：基于系统 JobScheduler 每 15 分钟后台检查，无常驻通知，支持重启与更新后自动恢复，电量降至 5% 及以下时追加紧急提醒。
- 多重安全防护：
  * 使用 AndroidKeyStore（AES-256-GCM）本地加密保存 Bot Token 与 Chat ID。
  * 强制 HTTPS 且仅信任系统根证书、禁止重定向，并关闭 Telegram 链接预览以保护一次性登录链接。
  * 已保存的 Bot Token 不回填明文、Chat ID 隐藏中间数字，并禁用云端与设备间迁移备份。

说明：使用前需准备自己的 Telegram Bot Token 与 Chat ID，建议同时为 Telegram 账号开启两步验证密码（2FA）。
